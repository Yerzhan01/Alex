# Лендинг: MagSafe-картхолдер

Flask-приложение: лендинг на трёх языках (`/` — казахский, `/ru`, `/en`), оформление заказа и оплата через Kaspi (DauysKit QuickPayments). Запускается через `main.py`, как и раньше: `gunicorn main:app`.

## Что где менять

- `shop/config.py` — название бренда, цены, цвета.
- `shop/i18n.py` — все тексты на трёх языках.
- `shop/static/images/photos/` — сюда кладутся фотографии товара.

## Переменные окружения

| Переменная | Зачем |
|---|---|
| `KASPI_INTEGRATION_ID` | ID интеграции DauysKit (без него оплата не создаётся) |
| `KASPI_WEBHOOK_TOKEN` | токен, который DauysKit присылает в `Authorization: Bearer …` |
| `ADMIN_PASSWORD` | пароль к списку заказов `/admin` (логин любой) |
| `DATABASE_URL` | база данных (по умолчанию SQLite `shop.db`) |
| `SESSION_SECRET` | секрет Flask |
| `SHOP_BRAND` | название бренда (по умолчанию `Elteres`) |

В DauysKit нужно указать callbackUrl `https://<домен>/kaspi_webhook` и тот же токен, что и в `KASPI_WEBHOOK_TOKEN`.

## Как проходит оплата

1. Покупатель выбирает цвета и количество, вводит имя, телефон, город и адрес.
2. Сервер считает сумму (каждые 2 шт — 45 000 ₸, одна — 25 000 ₸), сохраняет заказ и создаёт счёт в Kaspi.
3. Покупатель попадает на страницу заказа, откуда его перекидывает в Kaspi.
4. После оплаты приходит webhook, заказ получает статус «Оплачен», а страница заказа сама показывает «Спасибо».
